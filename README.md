### 🚀 Featured Projects

#### 🔎 CatalogIQ — GenAI Data Catalog Assistant
An end-to-end data platform: ingests public clinical trial data from the **ClinicalTrials.gov API** into **AWS S3**, transforms it in **Databricks** using a bronze → silver → gold (medallion) architecture, and exposes an **LLM assistant** that answers questions over table and column metadata.

`Python` `SQL` `AWS S3` `Databricks` `LLM` `GitHub Actions`

#### 📰 NewsOnTips — News Platform
Full-stack news site with a Telegram bot, ingesting articles from **NewsAPI.org**. Containerized with **Docker**, shipped through **GitHub Actions** CI/CD, and deployed on **AWS EC2**.

`React` `Node.js` `MongoDB` `Docker` `GitHub Actions` `AWS EC2`
